# Changelog

## 1.0.0

- Initial release of FunTerm.
- Added terminal colors, rainbow and RGB gradients.
- Added meme-style logger and original synthesized FAAAA, success, and warning sounds.
- Added banners, boxes, tables, dividers, spinners, and progress bars.
- Added a shell-free command runner with output capture, timeout, and automatic result reporting.
- Added CommonJS, ESM, TypeScript declarations, and theme configuration.
