# Themes

Select a theme with `fun.config.set({ theme: 'meme' })`.

| Theme | Feel | Accent palette |
|---|---|---|
| `meme` | Playful, loud, default | Green, cyan, yellow, red, magenta |
| `arcade` | Retro game terminal | Green, blue, yellow, magenta, cyan |
| `rainbow` | Maximum color | Rainbow success and error headings |
| `minimal` | Low-noise output | White, green, yellow, red |

Themes affect logger accents. `fun.colors` methods remain directly available in every theme. Set `colors: false` or define `NO_COLOR` to disable ANSI color sequences.
